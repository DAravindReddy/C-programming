union:
-----
union is same like structure. but difference in memory. In structures memory allocates continuesly including pading. But in union highest member of size will allocates the memory. It is sharable to another member.

Eg:
union Test
{
	int temp;
	float h;
}var;
here 4bytes of memory is allocated, And it is shareable.
