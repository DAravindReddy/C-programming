
============================Pointers===================================
pointer:
It is a variable.
It is used to store address of another variable.
Eg?:
int c = 10;
int *ptr = &c;

Pointer Rules:
1. Pointer is an integer:
-------------------------
->It stores the data(integral type)
->size of the address is depends on bitness of the system
Eg: int *ptr = &x; // ptr holds the integral value(address)

2. Referencing and dereferencing:
--------------------------------
->Reference: it is the process of storing the address of variable
	int *ptr = &ch; //referencing
->Dereference it is the process of accessing value of the variable
	*ptr = 10; //dereferencing
3. pointer means contains/holds:
-------------------------
->int *ptr = &x;
->ptr holds the address of the variable.

4. Pointer type:
----------------
->size of the pointer is does not depends on the data type. It depends on system bitness.
->here fetching of address is difference.
->when we are dereferncing we will get difference.
Eg:
int x = 10;
int *ptr = &x;
char *cptr = &x;
printf("%d", *ptr); // 10
printf("%d", *cptr);// 0

==>Endianess system:

	2. Little
1.Big:					2.littel

-lowest address msb byte is stored	-lowest address lsb byte is stored
Eg: to find the system is little endian or big endian
int main()
{
	int c = 0x12ABCDEF;
	char *ptr = &c
	if(*ptr == 0x12)
		printf("Big");
	else
		printf("Little");
	return 0;
}
